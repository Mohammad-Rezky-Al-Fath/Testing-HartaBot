# Test Plan: Ruang Lingkup (Scope)
Fokus pengujian fase ini adalah pada:

1. **Fungsi Inisialisasi:** Menguji respons bot terhadap perintah dasar (seperti /start) dan menu navigasi awal (pemilihan mode).

2. **Pemrosesan Input Angka (Parsing):** Menguji kemampuan bot dalam membaca berbagai format nominal uang (misalnya angka penuh "500000" vs singkatan "500rb" atau "2jt").

3. **Logika Kategorisasi:** Menguji akurasi bot dalam mengelompokkan jenis pengeluaran/pemasukan berdasarkan kata kunci atau konteks kalimat.
