# 🤖 Proyek Testing HartaBot
Repositori ini merupakan pemenuhan tugas Pertemuan 3 Mata Kuliah Testing dan Implementasi Sistem mengenai Kolaborasi Tim. Objek studi kasus pengujian kami adalah AI Chatbot Telegram: **HartaBot**.

7. **Iyan** - Stakeholder/Reviewer (Review hasil & approval)

## 📁 Struktur Repositori
Repositori ini mengadopsi prinsip *One Source* dan terbagi menjadi:
- `01_Test_Plan/` : Berisi rencana pengujian dan batasan sistem.
- `02_Test_Cases/` : Skenario spesifik yang diuji.
- `03_Test_Data/` : Data yang digunakan untuk pengujian (jika ada).
- `04_Execution_Evidence/` : Bukti pengujian terhubung.
- `05_Defect_Log/`  : temuan defect/bug pada sistem
- `06_Test_Report/` : Laporan akhir pengujian.

*Catatan: Pencatatan Defect Log (Manajemen Bug) dilakukan melalui fitur **Issues** dan pemantauan pekerjaan (Testing Backlog) dilakukan melalui fitur **Projects**.*
